# FieLanzen Offline 0.2.0

**Reguläres Android-Release · 26. November 2026**  
**Regular Android release · 26 November 2026**

## Änderungen (Deutsch)

Version **0.2.0** fasst die zuvor in Alpha 32 bis 37 entwickelten Funktionen zusammen und ersetzt die Alpha-Versionskennung. Gegenüber der zuletzt signierten Alpha 37 enthält dieses Release vor allem die Umstellung auf reguläre SemVer-Versionierung, einen höheren Android-versionCode und vollständigere GitHub-Release-Notizen.

### Übersicht und Buchungen

- Einheitliches Layout der lokalen Offline-Ansicht und des optionalen Dashboard-Servermodus: Buchungskarten, Statuskennzeichnungen, Filter und Suche.
- Monatsvergleich auf der Übersicht mit frei wählbaren Monaten, Konto-, Kategorie- und Währungsfiltern.
- Kompakte, tastaturfreundliche Vorschläge für Empfänger und Kategorien beim Erfassen von Buchungen und Regeln.
- Lokale SQLite-Daten und Dashboard-Serverdaten bleiben strikt getrennt; es gibt keine automatische Synchronisierung oder Übertragung.

### Historie und Diagramme

- Der bisherige Reiter „Monat“ heißt **„Historie“** und zeigt Monatssummen, Kennzahlen sowie Einnahmen-/Ausgabenübersichten.
- Vollständige historische Monatsdaten und Kategorienauswertungen werden im Servermodus über die Mobile-API berechnet, nicht aus nur teilweise geladenen Buchungsseiten hochgerechnet.
- SVG-Balken und SVG-Kreisdiagramme funktionieren unter der unverändert restriktiven Android-WebView-Sicherheitsrichtlinie.
- Höchste Einzelbuchungen können über die optionale Dashboard-API-Antwort dargestellt werden.

### Serverfunktionen und Sicherheit

- Wiederkehrende Regeln im Servermodus: Anzeigen und bei vorhandener Capability und Berechtigung verwalten; die serverseitige Ausführung bleibt Aufgabe des Dashboards.
- **Kontostandsabgleich direkt in Android**, ohne Browserweiterleitung: tatsächlichen Ist-Saldo eingeben, Differenz als Vorschau sehen und die vom Server erzeugte Korrekturbuchung bestätigen.
- Schutz bei Verbindungsabbruch durch Speicherung des unveränderten Requests mit derselben UUID; bei Saldoänderungen erneute ausdrückliche Bestätigung statt automatischer Konfliktübernahme.
- Schreibfunktionen benötigen die jeweilige API-Capability und ausreichende Rechte. Die lokalen Finanzdaten und Backupformate bleiben unangetastet.

### Veröffentlichung

- Signierte Release-APK mit SHA256-Prüfsumme, vollständigem Quelltext zum Tag und einem aussagekräftigen Änderungsverlauf.
- Neues Versionsschema **0.2.0** (statt 0.1.0-alpha.37); Android-versionCode **20000** (zuvor **36**), damit ein Update derselben Signatur möglich bleibt.
- Die Quellcode-, API- und Sicherungsformate wurden für die Versionsumstellung nicht verändert.

**Testhinweis:** Automatisierte TypeScript-, Regressionstest- und APK-Build-Prüfungen laufen im Release-Workflow. Sie ersetzen keinen vollständigen Gerätetest. Die Serverfunktionen setzen einen entsprechend aktualisierten Finanzdashboard-Server voraus.

## Changes (English)

**0.2.0** is the first non-prerelease Android version, consolidating functionality introduced in development alphas 32–37. Compared with signed alpha 37, this version chiefly updates versioning, the monotonic Android versionCode, and GitHub release documentation.

- **Consistent local/server UI:** shared booking cards, search and filters; local SQLite and server finances remain separate.
- **Overview:** configurable two-month comparison, account/category/currency selection and keyboard-aware payee/category suggestions.
- **History:** full server-side monthly reports and category breakdowns, with CSP-safe SVG bars and donut charts. Partial booking pages are never represented as complete historical reports.
- **Recurring rules:** server rules can be viewed and managed where the Dashboard exposes the feature and sufficient permissions are granted; the server remains the scheduler.
- **Balance reconciliation:** perform account adjustments inside Android using the Dashboard's authorized API, with preview-only local delta, server-side booking, durable idempotency UUID, and explicit reconfirmation on conflicts.
- **Security and compatibility:** no implicit sync, no local data migration, unchanged package ID and backup formats. Android versionCode increases from **36** to **20000** for same-certificate upgrades.
- **Release:** signed APK, SHA256 checksum, complete tagged source and these bilingual notes. Automated build and regression checks do not replace real-device testing.

Historical alpha builds remain available as earlier prereleases; **this 0.2.0 release is not marked prerelease**.
